# test

A starter project initialized with Google Antigravity.

## Overview

This project was initialized in `Users\raymo\desktop\projects\test` and is configured with version control ready for development.

## Getting Started

### Prerequisites

- [Git](https://git-scm.com/) installed on your machine.

### Working with Antigravity

- **Antigravity Desktop**: Go to **Projects** in the left sidebar and select this folder (`C:\Users\raymo\Desktop\projects\test`).
- **Antigravity IDE**: Open the folder via **File > Open Folder...**.
- **CLI (`agy`)**: Open PowerShell, navigate to this directory, and run `agy`.

To customize Antigravity's behavior for this project, you can add instructions to `.agents/rules`.
